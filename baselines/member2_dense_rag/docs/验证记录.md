## 自动测试

19 项测试全部通过，日志见 test_results.txt。包括原 13 项通用/Dense 回归与新增 6 项：Parquet/JSONL 一致性；上游 manifest 和 split 校验；公开输入标签与 span/text hash 检查；无答案请求导出；段落 macro recall、排除无 gold 和缺失预测处理；PubMedQA 分类提示词。

## 真实上游数据

完整读取并通过本适配器检查 QASPER 17,653 个 chunks、PubMedQA 1,024 个 chunks，两个数据集的 Parquet 与 JSONL 规范化结果一致。评测侧读取 QA，核实 QASPER 共 3,598 题，其中 2,991 题可计算段落 recall；PubMedQA 1,000 题均无段落 gold。QASPER dev 导出 1,005 条无答案请求，PubMedQA 导出 1,000 条；请求不含 gold、答案或 decision。

真实 BGE 小样本使用 QASPER 论文 1503.00841（15 chunks）及 PubMedQA 论文 21645374（1 chunk），各运行一个问题，完成 Parquet 读取、编码、FAISS 建库、索引重载、检索和 preview 生成。分数、段落字段、split、上游配置和耗时已保存至 artifacts/upstream_qasper 与 artifacts/upstream_pubmedqa。两套样本按实际 BGE tokenizer 加特殊 token 后均未超过 512 长度。

QASPER 单题 paragraph recall@5 为 1/3；PubMedQA 该指标返回 null。只是接口冒烟样本，不能视作全量 baseline 成绩。完整机器记录见 upstream_validation.json。

本适配器检查不替代上游完整校验器：未重新执行其全部 24 项检查，也未逐条读取原段落检查 span 的文本上界。
