# 跨数据集可比性说明（QASPER 结果 vs CG-RAG 在 PubMedQA-1k 的结果）

> 2026-11-01　|　回答两个问题：① 耦合边替换引用边是否仍属 CG-RAG 的框架；② 在 PubMedQA-1k 上跑一遍，能不能和 QASPER 上的结果比。

---

## 1. 耦合边替换：属于框架，不属于复现

**属于**：LeSeGR 的两条门控信号只依赖邻居集合与向量，不依赖边是从哪来的——

$$\delta_{qj}=f_{sparse}(q,c_j),\qquad \alpha_{ij}=\mathrm{MLP}(c_i^{dense}\ominus c_j^{dense})$$

换边不改变任何一个公式。而且 CG-RAG 的跨文档边本身也是"论文 $v$ 的 chunk ← 被引论文 $u$ 的 Top-$n$ chunk"，耦合边展开到 chunk 级后**机制完全同构**。

**不属于**：耦合边是无向、同期、主题同源；引用边是有向、时间单向、知识流向。两者是**不同的关系类型**，不能声称复现。

## 2. QASPER 上的结果 vs PubMedQA-1k 上的结果：能比什么、不能比什么

### 2.1 结论先行

**绝对数字不可比；相对增益只能定性对照。**

### 2.2 可比性分层

| 层次 | 是否可比 | 原因 |
|---|---|---|
| **绝对指标**（Hit@1 / Acc / F1） | ❌ **不可比** | 任务、指标、语料池、图构造四处不同（见 2.3） |
| **相对增益**（dense → dense+graph 的提升） | ⚠️ **只能定性** | 同一数据集内自己的 B0 vs B2 可比；跨数据集只能说"方向是否一致、量级是否相当" |
| **机制结论**（结构信息是否有效、哪种边更有用） | ✅ 可比 | 这是方法层面的结论，与数据集无关 |
| **失败模式**（图扩展是否引入噪声、2-hop 是否退化） | ✅ 可比 | 同上 |

### 2.3 四处不可比的具体原因

**① 任务与指标不同。**
PubMedQA-1k 是 yes/no/maybe **三分类**，核心指标是 Acc / $F_1$；QASPER 是**证据定位问答**，核心指标是 evidence recall + answer $F_1$。两个指标之间没有换算关系。

**② 检索语料池规模不同，而这直接决定难度。**
CG-RAG 把 PubMedQA-1k 扩成 **7,849 篇**的语料来算 Hit@1。如果我们只用 1,000 条摘要当语料，池子小 7.8 倍，**同样方法的 Hit@1 必然更高**——这不是方法更强，是任务更简单。

**③ 图不是同一个图。**
他们的是自建引文图（**未公开**，GitHub 无仓库）；我们的是耦合/实体图。

**④ 评测金标准的粒度，论文没有说清。**
论文只说 PubMedQA-1k 有 "human-labeled gold-standard retrieval and answer annotations"，**没说明 retrieval gold 是段落级还是摘要级**。这直接影响 recall 的分母，是不可复现的模糊点。

### 2.4 如果一定要在 PubMedQA 上和论文对话，怎么做才站得住

1. **明写语料口径**：例如"我们使用 1,000 条摘要作为检索语料（论文为 7,849 篇）"，并说明池子大小会系统性抬高绝对分数。
2. **只报相对增益**：`dense-only → dense+graph` 的提升，与论文的 +4.8pp（Hit@1 0.913→0.961）比**方向和量级**，不比绝对值。
3. **把差异归因写清楚**：语料规模、图构造方式、金标准粒度，三点逐条说明。
4. **不要并排放表格**。并排会诱导读者直接比较，而这两个数不在同一坐标系里。

---

## 3. 一句话总结

> 耦合边是 CG-RAG 框架的**合法实例化**，不是复现；PubMedQA-1k 上的结果可以作为**跨领域一致性证据**，但不能作为**和论文数字对比的主表**。真正的方法结论应该来自 QASPER 上的 B0/B1/B2 三档消融——那是同一数据集、同一指标、同一 pipeline，归因是干净的。
