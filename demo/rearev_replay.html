About this view

The graph is a local subset expanded from saved relation paths. It is not the complete model input.

The GNN block illustrates question-guided message passing, representation updates and score readout. Intermediate messages and layer values were not recorded.

Final node probabilities come from an existing model run. They retain the original full-pool values and are not renormalized over this view. Bar lengths are scaled to the largest visible score.

This page makes no backend requests and does not execute a model.
